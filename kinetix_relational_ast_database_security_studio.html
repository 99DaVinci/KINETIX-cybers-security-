Interactive Sandbox
1. Naive Keyword Blacklist (`OR`, `SELECT`, `UNION`) Bypassable

Strips uppercase SQL keywords. Easily bypassed using mixed case (oR, uNiOn) or symbolic operators (||).

2. SQL Comment Sequence Blocker (`--`, `/*`) Incomplete

Blocks queries containing inline comment tokens. Fails against well-formed boolean tautologies like ' OR 'a'='a that balance quotes without comments.

3. Parameterized Prepared Statements (`$1, $2`) Mathematically Sound

Compiles the SQL Abstract Syntax Tree on the database server before binding parameters. User input is strictly treated as a scalar literal value.
